Sign in to edit the menu

Saving goes straight to the website, so this page needs a GitHub access key for the haveli-site project. You only set this up once per device.

  1. Open GitHub → New fine-grained token while signed in as thevaletai.
  2. Name it “Haveli menu”. Under Repository access choose Only select repositories → haveli-site.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it and paste it below.

Change prices right in the price boxes. Use Edit for descriptions, labels and spice level. Nothing goes live until you press Publish.
